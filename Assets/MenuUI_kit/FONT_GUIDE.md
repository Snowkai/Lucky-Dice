# Font guide

+The reference mockup was generated as an image, so it does not contain an actual embedded font file.
+
+## Recommended match
+- Title `DICE`: **Cinzel Bold**, uppercase, tracking 8-14%.
+- Dice labels `D4-D20`: **Cinzel Bold**, tracking 0-4%.
+- `Display score`: **Cinzel SemiBold**.
+- Numeric values: **Cinzel Regular** or **Roboto Slab Regular** for clearer digits.
+
+Cinzel is available from Google Fonts under the SIL Open Font License. Download the official TTF files and create TextMeshPro Font Assets in Unity.
+
+Suggested colors:
+- Primary text: `#2B211B`
+- Soft shadow: `#6E4D2F` at 35% alpha
+- Ivory icons: `#FAEFD5`
+- Brass: `#B8863B`
+
+The font itself is not included because the generated screenshot did not use a real font file.
